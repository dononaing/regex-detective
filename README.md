# Regex-детектив

Консольная и визуальная детективная игра для тренировки регулярных выражений на Python.

## Правила игры
Игрок выступает в роли детектива и шаг за шагом расследует дело. В каждом раунде даётся описание правила и примеры данных. Задача игрока — ввести подходящее регулярное выражение:
* Если шаблон верный, игрок получает улику и переходит к следующему раунду.
* Если допущена ошибка, игра покажет пример, на котором шаблон сломался, и даст попробовать снова.
* В консольной версии в любой момент можно ввести слово `подсказка`.

## Как запустить игру

### 1. Консольная версия
Откройте терминал в корневой папке проекта и выполните:
```bash
python main.py
```

### 2. Визуальная версия (веб-интерфейс на Streamlit)
1. Установите библиотеку Streamlit:
```bash
pip install streamlit
```
2. Запустите веб-интерфейс командой:
```bash
streamlit run ui.py
```
