# Regex-детектив

Консольная детективная игра для тренировки регулярных выражений на Python. 

## Правила игры
Игрок выступает в роли детектива и шаг за шагом расследует дело. 
В каждом раунде даётся описание правила и примеры данных.
 Задача игрока - ввести подходящее регулярное выражение:
 
* Если шаблон верный, игрок получает улику и переходит к следующему раунду.
* Если допущена ошибка, игра покажет пример, на котором шаблон сломался, и даст попробовать снова.
* В любой момент можно ввести слово `подсказка`.

## Как запустить игру
1. Убедитесь, что у вас установлен Python.
2. Откройте терминал в папке с проектом и выполните команду:
```bash
python main.py
```
